# first-landing-page

Modernes Premium-Portfolio / Agentur-Website in Next.js, Tailwind CSS und Framer Motion.

## Installieren

1. Öffnen Sie das Projektverzeichnis:
   `cd c:\Users\ulvir\Desktop\first-landing-page`
2. Installieren Sie die Abhängigkeiten:
   `npm install`
3. Starten Sie den Entwicklungsserver:
   `npm run dev`

## Testen

Öffnen Sie den Browser und gehen Sie zu:

`http://localhost:3000`

## Inhalte

- `src/app/page.tsx` — Hauptseite mit allen Sektionen
- `src/app/layout.tsx` — globale HTML-Struktur und Meta-Angaben
- `src/app/globals.css` — globale Tailwind- und Design-Stile
- `src/components/Navbar.tsx` — responsive Navigation mit Mobile-Menu
- `src/components/SectionHeading.tsx` — wiederverwendbarer Abschnittstitel
